# Bookstore Management System

This project is a modular bookstore management system developed using Python.

## Features
- Add and manage books
- Search books
- Track sales and income
- Maintain staff details
- Read Book

## Technical Overview
- Multi-file modular architecture
- Central controller using main.py
- File handling for data storage
- Designed as a structured system for managing bookstore operations
